# Closet Archive

自分のクローゼットを図鑑のように管理し、AIでスタイリングを提案してもらう個人向けWebアプリ。

## 背景
服は多いのに「何を持っているか」「何を着ていないか」「何にいくら使ったか」が把握できず、次に何を買うべきか迷っていた。
自分の服を記録して見える化し、手持ちの服を活かしたスタイリングを考えられるツールを作る。

## 機能
- **図鑑**：服の写真をアップロード → 背景を自動で切り抜いて番号付きで登録。AIがカテゴリ・色・素材を自動入力
- **コーデ日記**：手持ちの服を組み合わせて平置き風に表示し、日付・メモ・着用写真と一緒に保存
- **AIスタイル提案**：クローゼットと「スタイルメモ」をもとに、手持ちの服だけでコーデを提案。新しい系統と買い足す服も提案
- **支出管理**：月別・カテゴリ別・ブランド別の支出と、着用単価（価格 ÷ 着用回数）

## 構成
| フェーズ | 内容 |
|---|---|
| v0 プロトタイプ | `prototype/index.html`。ブラウザだけで動く1ファイル版で、欲しい機能を検証する |
| v1（予定） | Django で作り直す。モデル：Item / Outfit / WearLog |

## 開発の進め方
機能ごとに Issue を立て、ブランチ → Pull Request → main へマージ。
